## 흐름

```
의무 카탈로그 ─────────────┐
(lawmap → 정책이 의무 id 참조) │
                             ▼
정책 팩(YAML) ─ compile ─▶ Semgrep CE 1회 ─▶ 세 값 판정(파일·함수 단위) ─┐   ← --judge none 이면 여기서 끝(모델 호출 0회)
                                         │ 모름 / 약한 대안만 참        │
                                         ▼                            │
                                  AI 판정기(질문 1개, 파일 1개)  ───────┤   ← --judge
                                                                      ▼
저장소 색인 ─────────────────────▶ 후보 단위(정책, 진입 파일 + 관련 파일)
(파일 역할, import 관계)                   │
                                          ▼
                            에이전트형 판정 (Claude API, 도구 사용)       ← --agent
                            · review: 정적 경고를 관련 파일까지 읽고 다시 본다
                            · combined: review + 정적 검사가 놓친 곳 찾기 + 찾은 곳 재확인
                            · independent: 정적 검사 없이 정책마다 찾기
                            · 읽기 전용 도구 셋(목록·읽기·검색), 저장소 밖 금지, 단위당 호출 상한
                                          │
                외부 전송 통제 ◀───────────┤  비밀값 가리기, 비밀 파일 거부, 보낸 목록 기록
                                          ▼
                              인용 관문(여러 파일) ─▶ 보고(글·JSON·SARIF) + 종료 코드 0/1/2
```

## 만들며 알게 된 것 (11/3 dev 저장소 20곳, 원자료 `~/.cache/policypack-eval/agent-dev-2026-11-03/`)

- 단위를 따로 물으면 같은 저장소·같은 정책의 두 단위가 반대로 답했다 → 같은 정책의 진입 파일을 한 대화로 묻는다(8cd5048).
- review(정적 경고만 다시 보기)는 잘못된 경고를 줄이지만, 정적 신호가 없는 곳은 후보가 되지 않아 놓친 것을 찾지
  못한다 → 결합 방식에 찾기 단계를 더했다(8824f27).
- 찾기·독립 검토가 낸 경고에는 실제로는 이행한 곳이 많이 섞였다. 같은 모델로 다시 물으면 자기 답에 거의 동의했고,
  다른 모델(sonnet)로 재확인하면 더 많이 풀렸다 → `--agent-recheck`(42dd4c1).
- 남는 차이는 해석이 갈리는 곳이다(시행령 제23조 ④ '명백함', 만 14세 자기 선언 체크박스). 도구는 '검토 필요 + 질문'
  으로 남긴다.
- API 가 응답하지 않는 요청 하나가 검사 하나를 28분 멈췄다 → 시간 초과는 한 번만 다시 보낸다(947a790).
- 네트워크가 끊기면 질문마다 재시도로 100초를 써서 검사가 끝나지 않았고, 독립 검토는 경고 0개·종료 코드 0으로 끝날
  상태였다 → 두 질문이 연달아 닿지 못하면 멈추고, 독립 검토는 답을 못 받은 정책이 있으면 1로 끝낸다(11/7).
- 비용(보수 단가): 저장소당 review 약 $0.02, 독립 $0.13, 결합 + sonnet 재확인 약 $0.2.

## 지키는 것

- `--judge none` 의 판정은 바뀌지 않아야 한다(골든 시험으로 고정). 모델 호출 0회, 외부 통신 0건.
- AI 결과는 정적 결과를 지우지 않는다. 두 결과를 함께 싣고, 무엇이 무엇을 바꿨는지 판정 경로에 남긴다.
- 에이전트 도구는 검사 대상 저장소 밖을 읽지 못하고, 쓰기·실행·네트워크 도구는 주지 않는다.
- 모델 id, 사용량, 에이전트가 읽은 파일을 보고서에 남겨 같은 실행을 다시 할 수 있게 한다.
