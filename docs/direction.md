# 방향 A — AI 중심 국내 법 검토 (2026-10-24 결정)

## 한 문장

국내 법령에서 코드에 흔적이 남는 의무를 지도로 만들고, 정적 신호로 후보를 찾은 뒤, AI 가 관련 파일을 여러 개
읽어 지켰는지 판단하되 **코드 줄을 인용한 판단만** 받아들이는 로컬 CLI.

과제명 "AI 기반 로컬 코드 보안·이슈 점검 CLI 도구"는 그대로다. 점검하는 이슈가 보안·품질 8유형에서 국내 법·정책
의무로 바뀌었고, 판정의 중심이 정적 규칙에서 AI 로 옮겨 간다.

## 왜 바꾸나

- **의무 대부분은 정적 규칙으로 가릴 수 없다.** 의무 지도(2026-10-15)에서 코드에 흔적이 남는 의무 795개 가운데
  Semgrep 조건만으로 가릴 수 있는 것은 11개(1.4%)였다. 606개(76%)는 코드의 뜻을 읽어야 하고, 178개(22%)는 여러
  파일·화면에 걸쳐 있다.
- **재현율을 막은 것은 판단력이 아니라 시야다.** 중간 평가(test F1 0.28)에서 놓친 양성 21건 가운데 15건은
  파일 하나만 보는 구조 때문이었다(생성형 AI 의 서버 파일, 나이를 다른 파일에서 받는 가입). AI 판정기를 켜면
  정밀도는 0.35 → 0.60 으로 올랐지만 재현율은 그대로였다.
- **계획서의 기술 일정과 맞는다.** 9~14주의 계획(코드 문맥 추출, AI 재검토, 독립 AI 검토, 근거 검증, 마스킹)은
  방향 A 에서 그대로 쓴다. 바뀌는 것은 대상 이슈다.
  계획서의 네 방식 비교 실험은 하지 않는다(2026-11-05, [decisions/0004](decisions/0004-no-accuracy-experiment.md)).

## 무엇이 그대로이고 무엇이 바뀌나

| 그대로 | 바뀐다 |
|---|---|
| 출력은 "검토 필요 + 근거 조문 + 확인 질문". 위반 판정이 아니다 | AI 가 판정의 중심이 된다. 정적 조건은 후보를 찾는 신호로 내려간다 |
| 방향성 신뢰: 약한 근거는 경고를 올릴 수만 있고 내릴 수 없다 | 판정 단위가 파일·함수에서 "흐름"(진입 파일 + 관련 파일)까지 넓어진다 |
| AI 의 '충족'은 코드에 글자 그대로 있는 줄을 인용해야 인정 | 인용이 여러 파일에 걸칠 수 있다(파일·줄·인용문) |
| 조문 원문을 해시로 고정(`_legal/`) | 정책은 의무 지도의 항목 id 를 가리킨다 |
| `--judge none` 이면 모델 호출 0회, 외부 통신 0건 | AI 를 켜면 보내는 범위를 미리 보이고 비밀값·개인정보를 가린다 |
| Semgrep CE 를 고치지 않고 별도 프로그램으로 부른다 | Semgrep 은 `StaticBackend` 뒤의 신호 공급자 하나다 |

## 하지 않는 것 (이번 학기)

- 정책 수 늘리기 경쟁. 지도는 범위의 분모를 보이는 근거이고, 이번 학기에 만들 목록이 아니다.
  새 정책은 kr-core 5개 + 개인정보의 외부 AI 전송(개인정보 보호법 제28조의8·제26조) 1개까지.
- 자체 파서·데이터 흐름 엔진. tree-sitter·TypeScript 컴파일러로 엔진을 새로 짜는 일은 학기 뒤로 미룬다.
- 일반 보안 취약점 규칙(SQL 주입, XSS). Semgrep·CodeQL·플랫폼 AI 리뷰가 이미 무료로 한다.
- 법률 판단. 도구는 검토할 곳을 찾고 묻는다.

## 이미 있는 것과의 차이

국내 법을 코드에서 보는 도구는 이미 여럿 있다(LawLint, privacy-scan-kr, klaws, pipa-guard, launch-doctor-kr,
AnsimCode, vibecode-checker). "최초"를 주장하지 않는다. 우리가 보여 줄 차이는 넷이다.

1. AI 의 판단을 인용 관문으로 검증한다. 코드에 없는 근거로는 경고를 내리지 못한다.
2. 판정이 세 값(충족 근거 발견 / 검토 필요 / 모름)이고, '모름'은 개발자에게 물을 질문이 된다.
3. 조문 원문 해시와 의무 지도로 "무엇을 보고 무엇을 보지 않는지"를 밝힌다.
4. 끝까지 동작한다. 같은 판정이 커밋 전 훅, CI(SARIF), 공개 저장소를 분석하는 웹 서비스에서 돌고, AI 에 보내는
   코드는 비밀값을 가린 뒤 보낸 목록을 보고서에 남긴다.

자세한 비교는 중간 보고서 2장에 있다([reports/](reports/)).
