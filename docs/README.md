- **사실과 계획을 섞지 않는다.** 구현된 것은 커밋 해시와 함께, 계획은 날짜와 함께 적는다.

  저장소에 올리지 않는 까닭은 공개 저장소 41개의 코드 조각이 섞여 있어서다.
- **결정은 고치지 않고 새로 쓴다.** 뒤집힌 결정은 상태를 '대체됨'으로 바꾸고 새 번호를 단다.
